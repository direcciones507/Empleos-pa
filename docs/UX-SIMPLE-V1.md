# UX SIMPLE V1

Estado: DECISIÓN DE PRODUCTO
Fecha: 17-sep-2026

## Regla central
Si un candidato necesita instrucciones para registrarse, el flujo es demasiado complicado.

## Candidato
Empleos.pa → Crear cuenta / iniciar sesión → Busco empleo → formulario guiado → revisar → aceptar condiciones → enviar → EMP-###### → listo.

Al regresar:
Iniciar sesión → Mi perfil → consultar/actualizar/renovar cuando corresponda.

Funciones de cuenta mínimas:
- iniciar sesión;
- cerrar sesión;
- recuperar contraseña;
- actualizar perfil.

## Empresa
Empleos.pa → Crear cuenta / iniciar sesión → Busco personal → formulario de vacante → revisar → aceptar condiciones → enviar → VAC-###### → pago/proceso.

## Formulario
- Nativo dentro de Empleos.pa.
- No Google Forms.
- Mobile-first.
- Campos grandes y legibles.
- Pasos cortos.
- Indicador de progreso.
- Anterior / Siguiente.
- Borrador automático.
- Revisión antes de enviar.
- Aceptación de condiciones integrada.
- Confirmación final limpia.
- Evitar menús y configuraciones innecesarias.

## Canales
La web es el canal principal.
WhatsApp puede existir únicamente como asistencia.
El registro, las vacantes y la operación principal no dependen de Meta, WhatsApp ni Natalie.

## Video de adquisición
El flujo debe ser suficientemente simple para poder demostrarse en un video corto grabado desde un teléfono para Instagram/TikTok: entrar → llenar → enviar → confirmación.
