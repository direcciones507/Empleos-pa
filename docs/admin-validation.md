# Validación del Admin

Antes de continuar con un nuevo bloque o fusionar esta rama:

1. Verificar el HEAD real de la rama.
2. Verificar los checks y workflows asociados al HEAD.
3. Si existe un workflow en curso, esperar su resultado.
4. Si falla, corregir antes de acumular otro bloque.
5. Fusionar únicamente con las validaciones requeridas en verde.
