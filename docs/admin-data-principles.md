# Principios de datos del Admin

- La API es la fuente de verdad para cifras y estados.
- El frontend presenta resultados; no duplica reglas comerciales críticas.
- La IA interpreta resultados estructurados; no inventa ni recalcula cifras operativas sin respaldo de la API.
- Los reportes distinguen actividad de un período de estado actual.
- Las acciones administrativas sensibles deben ser auditables.
