# Alcance administrativo de Vacantes

La administración de vacantes debe mostrar de forma trazable el ciclo operativo de cada solicitud y conservar el historial de estados.

## Vista prevista

- Código de vacante.
- Empresa.
- Puesto.
- Tipo de solicitud.
- Ubicación.
- Estado.
- Precio/paquete cuando corresponda.
- Fechas relevantes.
- Entregas asociadas.

La política comercial específica ante ausencia de candidatos compatibles debe quedar definida antes de automatizar cobro o entrega para vacantes laborales.
