# Orden incremental de implementación

1. Dashboard base.
2. Resumen operativo de Candidatos.
3. Resumen operativo de Empresas.
4. Reportes estructurados desde API.
5. Servicios y métricas de disponibilidad/cobro/entrega.
6. Vacantes y entregas.
7. Fichas administrativas ampliadas.
8. Interfaz de consultas administrativas asistidas por IA.

Cada etapa debe reutilizar datos y endpoints existentes cuando sea posible y evitar duplicar reglas de negocio en el frontend.
