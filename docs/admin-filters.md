# Filtros previstos

Los módulos administrativos deberán mantener filtros simples y útiles para móvil.

Filtros comunes previstos:

- Estado.
- Período.
- Provincia.
- Distrito cuando corresponda.
- Búsqueda textual por identificadores y nombres relevantes.

Los filtros deben traducirse a consultas de API cuando el volumen de datos requiera paginación o agregación del lado del servidor.
