# Ejemplo de reporte asistido

Pregunta administrativa:

`Dame el reporte de hoy.`

Flujo esperado:

1. El backend autentica al administrador.
2. Consulta los agregados reales del período.
3. Entrega a la IA un objeto estructurado con las cifras autorizadas.
4. La IA redacta un resumen y destaca tendencias o pendientes sin alterar las cifras recibidas.
