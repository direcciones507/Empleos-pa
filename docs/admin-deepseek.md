# Motor de IA administrativo

El motor previsto para la capa de interpretación administrativa es DeepSeek.

Su integración se realizará detrás de una capa del backend que controle autenticación, autorización, selección de herramientas/endpoints y formato de los datos enviados al modelo.

DeepSeek podrá redactar y explicar reportes, pero las cifras y estados provendrán de la API de Empleos.pa.
