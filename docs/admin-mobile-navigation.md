# Navegación móvil prevista

El Admin se diseña con prioridad móvil.

Navegación principal prevista:

- Inicio.
- Candidatos.
- Empresas.
- Vacantes.
- Más.

`Más` podrá agrupar Servicios, Reportes, Pagos, Auditoría y configuración administrativa cuando esos módulos estén disponibles.

El Inicio funciona como tablero de situación; las operaciones detalladas permanecen dentro de cada módulo.
