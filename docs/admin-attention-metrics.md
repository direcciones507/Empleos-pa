# Métricas de atención administrativa

El Dashboard debe diferenciar métricas informativas de situaciones que requieren acción.

Ejemplos previstos:

- Candidatos próximos a vencer.
- Candidatos vencidos.
- Pagos pendientes de revisión.
- Solicitudes de servicio sin disponibilidad.
- Solicitudes con disponibilidad pendientes de pago.
- Entregas pendientes.

Cada indicador accionable deberá poder conducir al subconjunto correspondiente cuando exista la vista administrativa necesaria.
