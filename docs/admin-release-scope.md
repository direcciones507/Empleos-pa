# Alcance de la primera entrega del Admin

La primera entrega busca mejorar visibilidad operativa sin introducir cambios en reglas de matching, pagos, migraciones o despliegue.

Incluye:

- Resumen principal más legible.
- Resumen de Candidatos.
- Resumen de Empresas.
- Contratos funcionales para Reportes y Servicios.

Las conexiones adicionales de backend y la integración del motor de IA se realizarán en bloques posteriores.
