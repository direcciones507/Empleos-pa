# Límite administrativo

Las funciones del Admin deben permanecer protegidas por autorización administrativa del backend.

La futura interfaz de preguntas y reportes con IA no amplía permisos: solo podrá consultar operaciones administrativas que el usuario autenticado ya tenga autorizadas.

Los cambios administrativos sensibles deberán conservar trazabilidad mediante la auditoría existente o su evolución correspondiente.
