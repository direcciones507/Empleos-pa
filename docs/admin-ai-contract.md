# Contrato de IA para el Admin

La futura capa de IA del panel administrativo consumirá únicamente datos autorizados y estructurados provenientes de la API de Empleos.pa.

## Responsabilidades de la API

- Consultar la fuente de datos.
- Aplicar permisos administrativos.
- Calcular conteos, estados, disponibilidad, ingresos y comparaciones cuantitativas.
- Entregar resultados estructurados y trazables.

## Responsabilidades de la IA

- Resumir resultados.
- Explicar tendencias y diferencias.
- Redactar reportes.
- Responder preguntas administrativas usando los resultados recibidos.

La IA no debe inventar registros ni actuar como fuente de verdad para cifras operativas.
